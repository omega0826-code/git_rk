# 마크다운 → PPT 슬라이드 제작 SKILL 가이드

## 개요

마크다운(.md) 형식의 워딩/분석 결과 파일을 **python-pptx** 라이브러리를 사용하여 프로페셔널한 PPT 슬라이드로 자동 변환하는 작업 절차입니다.

---

## 전제 조건

### 필수 라이브러리
```bash
pip install python-pptx
```

### 입력 파일 형식 요구사항

마크다운 파일은 아래 구조를 따라야 합니다:

```markdown
# 문서 제목 (→ PPT 표지 제목으로 사용)

## 1. 섹션 제목 (→ 슬라이드 제목)

● 핵심 결과 텍스트... **굵은 강조** 포함 가능 (→ 메인 텍스트)

- 세부 분석 항목 1 (→ 불릿 포인트)
- 세부 분석 항목 2
- 세부 분석 항목 3

---

## 2. 다음 섹션 (→ 새 슬라이드)
...
```

| 마크다운 요소 | PPT 매핑                              |
| ------------- | ------------------------------------- |
| `# 제목`      | 표지 슬라이드 타이틀                  |
| `## N. 제목`  | 본문 슬라이드 (섹션 번호 배지 + 제목) |
| `● 텍스트`    | 핵심 결과 카드 영역 (메인 텍스트)     |
| `- 텍스트`    | 세부 분석 불릿 포인트                 |
| `**텍스트**`  | Bold + 강조색 적용                    |

---

## 작업 절차

### Step 1: 워딩 파일 확인

```bash
# 파일 존재 및 인코딩 확인
file --mime-encoding input_wording.md
head -20 input_wording.md
```

마크다운 파일이 UTF-8 인코딩이고, 위 입력 형식을 따르는지 확인합니다.

### Step 2: 스크립트 실행

```python
from create_wording_ppt import build_presentation, DesignTheme

# 기본 테마로 실행
build_presentation(
    md_path="path/to/wording.md",
    output_path="path/to/output.pptx"
)

# 커스텀 테마로 실행
custom_theme = DesignTheme(name="커스텀", bg_primary=(0x2D, 0x2D, 0x2D), ...)
build_presentation("wording.md", "output.pptx", theme=custom_theme)
```

또는 커맨드라인에서 직접 실행:

```bash
python create_wording_ppt.py
# → 스크립트 하단의 경로 설정을 미리 수정한 후 실행
```

### Step 3: 결과 확인

- [ ] 출력 `.pptx` 파일이 생성되었는지 확인
- [ ] PowerPoint에서 열어 슬라이드 수 확인
- [ ] Bold 텍스트가 올바르게 적용되었는지 확인
- [ ] 레이아웃/디자인이 의도대로 나타나는지 확인

## 커스터마이징 포인트

### 1. 표지 정보 변경
`build_presentation()` 호출 시 `add_title_slide()` 파라미터 수정:
- `title`: 프로젝트 제목
- `subtitle`: 부제목
- `date`: 날짜

### 2. 요약 슬라이드 인사이트
`add_summary_slide()` 내 `insights` 리스트를 프로젝트에 맞게 수정.

### 3. 디자인 테마 변경
`ppt_design_guideline.md`의 테마 추가 방법을 참고하여 새 `DesignTheme` 인스턴스 생성.

## 문제 해결

| 증상                     | 원인                  | 해결                        |
| ------------------------ | --------------------- | --------------------------- |
| 한글 깨짐                | 인코딩 불일치         | 마크다운 파일 UTF-8 확인    |
| Bold 미적용              | `**` 미닫힘           | 마크다운 `**` 쌍 확인       |
| 슬라이드 누락            | `##` 헤더 형식 불일치 | `## N. 제목` 형식 준수      |
| PowerPoint에서 폰트 깨짐 | '맑은 고딕' 미설치    | 테마에서 `font_family` 변경 |
