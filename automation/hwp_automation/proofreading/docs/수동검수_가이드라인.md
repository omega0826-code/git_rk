# HWPX 수동검수 가이드라인

## 목적

자동 검수 결과를 사람이 최종 송부본 관점에서 빠르게 확인할 수 있도록,
실무적으로 중요한 점검 기준만 정리한다.

## 1. 우선 확인 항목

### 1-1. 편집 메모 잔존
- `워딩을 수정합니다`
- `전체 합계를 다시 맞추었습니다`
- `연도별, 항목별로 구분하여 수치를 통일하였습니다`
- `테이블 수정 완료하였습니다`
- `재산정하였습니다`
- `페이지 번호 추후에 수정`

위 문구는 최종 송부본에서 그대로 남으면 안 되므로 우선 확인한다.

### 1-2. 미완성 문장
- `...사업비는`
- `...분석용 사업비는`
- `...으로`
- `...에서`

문장이 조사나 어미 없이 끊긴 경우는 실제 누락일 가능성이 높다.

### 1-3. 본문-표 수치 불일치
- 본문 요약 수치
- 표의 합계행
- 표의 연차별/세부 행 합산 결과
- 최종 결과표의 동일 항목

같은 항목이 여러 표에 반복되면 하나의 기준값으로 통일되어야 한다.

## 2. 자동 검수 오탐 주의

### 2-1. 율/률 예외
- `할인율`처럼 `ㄴ` 받침 뒤의 `율`은 정상 표기다.
- `선율`처럼 `ㄹ` 받침 뒤의 `율`도 정상 표기다.

따라서 받침이 있다고 모두 `률`로 바꾸면 안 된다.

### 2-2. 병합셀 표
- 소계 행 + 하위 행이 함께 있는 표는 자동 합산 검사가 과다 경고를 낼 수 있다.
- 이 경우 표 구조를 먼저 확인하고, 실제 오류인지 병합 구조 때문인지 구분한다.

### 2-3. 연차표
- 연도별 값이 길게 반복되는 표는 `연속 어절 중복` 경고가 많이 생길 수 있다.
- 숫자 반복 경고는 실제 중복 오기인지, 연차 배열 특성인지 직접 확인한다.

## 3. 검수 결과 전달 형식

사람이 직접 수정할 경우에는 아래 형식이 가장 유용하다.

| 페이지 | 위치 | 구분 | 원본 | 수정 |
| --- | --- | --- | --- | --- |
| 17 | 21줄 | 본문 | 원문 일부 | 교체 문장 |
| 21 | `< 상업시설편익 연차별 산정 결과 >` | 표 | 합계행 원문 | 수정값 |

## 4. 페이지 기준 줄번호

- 줄번호는 **해당 페이지의 첫 줄을 1줄로 두는 상대 줄번호**를 우선 사용한다.
- 절대 줄번호만 있으면 실제 문서에서 찾기 번거롭다.
- CSV와 체크리스트 출력물에도 페이지 기준 줄번호를 포함하는 것을 권장한다.

## 5. 출력물 권장

### 5-1. 기본 산출물
- `typo_check_report.md`
- `typo_check_detail.csv`

### 5-2. 수동 수정용 산출물
- A4 인쇄용 체크리스트 PDF

사용 예:

```bash
python run_typo_check.py sample.hwpx --output-dir output/review
python export_printable_checklist.py output/review/typo_check_detail.csv
```

## 6. 최종 검수 순서

1. 편집 메모 잔존 제거
2. 미완성 문장 보정
3. 표 합계와 본문 요약값 대조
4. 최종 결과표의 연동 수치 재확인
5. 인쇄용 체크리스트로 마지막 눈검수
