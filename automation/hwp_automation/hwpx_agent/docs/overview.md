# hwpx_agent 개요

## 왜 새 폴더를 만들었는가

기존 `hwp_automation`에는 파서, 수정기, 교정기가 따로 있습니다.
이번 단계에서는 이를 하나의 호출형 시스템으로 묶기 위한 최소 골격을 `hwpx_agent` 안에 독립적으로 만들었습니다.

## 이번 단계 목표

1. 새 통합 폴더를 만든다.
2. 공통 JSON 스키마를 정한다.
3. 테스트 파일 1건을 기준으로 자산화 파서를 만든다.

## 이번 단계 산출물

- `schemas/`: 문서, 블록, 교정 이슈 공통 JSON 스키마
- `src/hwpx_agent/`: 자산화 파서와 CLI
- `runs/<run_name>/`: 실제 테스트 파일 자산화 결과
