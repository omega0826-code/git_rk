# 1차 완료 기준

## 이 문서의 목적

이 문서는 `hwpx_agent`의 1차 구현 범위를 어디까지 완료로 볼지 고정하기 위한 문서입니다.

즉, 지금 시점에서 "무엇이 끝났고", "무엇은 아직 다음 단계인지"를 명확히 정리합니다.

## 1차 완료 범위

현재 1차 완료로 인정하는 범위는 아래와 같습니다.

- HWPX 패키지 분해
- 본문 문단 자산화
- 표 자산화
- 표 셀 자산화
- 이미지 바이너리와 이미지 배치 자산화
- 페이지 번호 정합화
- 교정 이슈와 원본 위치 연결
- 검토 파일 생성
- 선택 수정안에서 rebuild plan 생성
- 안전한 텍스트 문단 복원
- 안전한 텍스트 표 셀 복원
- 실행 결과 검증 자동화

## 실제 검증 완료 항목

테스트 파일 `2023_mei_workforce.hwpx` 기준으로 아래 항목을 실제 확인했습니다.

- 페이지 수 `239` 정합
- `origin_type=table_cell` 이슈 생성
- rebuilt `.hwpx` 한글에서 정상 열림
- 선택한 문단 수정 반영
- 선택한 표 셀 수정 반영
- `run_validate.py` 기준 검증 `pass`

## 1차 완료 기준에서 지원하는 것

- 본문 텍스트 문단 수정
- 안전한 텍스트 표 셀 수정
- 페이지 번호 추적
- 원본 XML 위치 추적
- 선택 수정안 기반 rebuild
- `run_pipeline.py` 기반 일괄 실행
- `run_validate.py` 기반 결과 검증

## 1차 완료 기준에서 제외하는 것

- 그림이 포함된 문단 자동 수정
- 복합 컨트롤 문단 자동 수정
- 복잡한 표 셀 자동 수정
- 각주, 미주, 글상자 내부 텍스트 자동 수정
- 머리말, 꼬리말, 마스터페이지 수정 복원
- 서식까지 완전히 동일한 새 HWPX 재생성
- 고도화된 맞춤법 엔진 통합

## 1차 완료 판정 기준

아래 조건을 모두 만족하면 1차 완료로 판단합니다.

1. 자산화 결과가 정상 생성된다.
2. 페이지 수가 기대값과 맞는다.
3. 교정 이슈가 `origin_id`와 연결된다.
4. `table_cell` 이슈가 생성된다.
5. 선택한 수정안이 rebuild plan으로 변환된다.
6. rebuilt `.hwpx`가 정상 생성된다.
7. rebuilt `.hwpx`가 한글에서 실제로 열린다.
8. 선택한 문단 또는 표 셀 수정이 실제로 반영된다.
9. `validation/validation_summary.json` 상태가 `pass`다.

## 운영 메모

현재는 "문서를 완전히 새로 생성하는 도구"가 아니라, "안전하게 분해하고, 선택한 수정만 다시 넣는 도구"로 보는 것이 맞습니다.

이 기준을 유지해야 다음 단계 확장에서도 품질 판단이 흔들리지 않습니다.
