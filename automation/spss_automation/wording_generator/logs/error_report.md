## 1. 한글 파일명 인코딩 실패

| 항목 | 내용 |
|------|------|
| 발생 버전 | v1.0.0 |
| 발생일시 | 2026-03-17 21:36 |
| 해결 버전 | v1.0.0 (래퍼 스크립트 추가) |
| 상태 | ✅ 해결됨 |
| 관련 | [Changelog v1.0.0](changelog.md) · [Troubleshooting #1](../docs/troubleshooting.md#1-한글-파일명-인코딩-오류) |

**증상**: cmd.exe에서 `--input`에 한글 경로 → `[ERROR] 파일을 찾을 수 없습니다`

**원인**: CP949 → UTF-8 변환 실패

**해결**: `run_now.py` 래퍼 스크립트 생성 (`PYTHONIOENCODING=utf-8`)
