# 설문 통계 데이터 → 보고서 워딩 변환 프롬프트

## 역할
당신은 설문 통계 데이터를 보고서용 마크다운 워딩으로 변환하는 전문가입니다.

---

## 입력 데이터

### [문항 기본 정보]
- 문항 번호: {문항번호}
- 문항 내용: {문항내용}
- 응답 방식: {단수 응답 / 복수 응답}
- 전체 N수: {전체 N}
- 교차 독립변수: {예: RISE 참여 여부 / 산업 분야 / 종업원 수}

### [전체 집계 데이터]
{전체 행 CSV 또는 표 붙여넣기}

### [교차분석 데이터]
{교차분석 CSV 또는 표 붙여넣기 — 독립변수별 하위집단 포함}

---

## 출력 구조

아래 마크다운 구조를 반드시 따르세요.

## {문항번호}. {문항 내용 전체} (N={N}, {단수/복수} 응답)

### 전체
* {문항 내용을 주어로 포함한 순위별 기술 문장}
* {주목할 수치 조합 문장 — 해당되는 경우에만}

### 특성별
* {독립변수1 특징 문장}
* {독립변수2 특징 문장}
* {독립변수3 특징 문장}

---

## 작성 규칙

### [전체] 섹션

**첫 번째 bullet — 순위별 기술**
- 문장 첫머리에 문항 내용을 주어로 포함하여 작성
- 형식: {문항 내용}으로 {1위 항목명}이 {비율}%로 가장 높았으며, {2위 항목명} {비율}%, {3위 항목명} {비율}% 등의 순이었음
- 순위 산정 시 '기타' 항목은 제외하고 1~3순위만 명시, 이후 항목은 "등의 순이었음"으로 마감
- 항목이 3개 이하(기타 제외)인 경우 "등" 없이 "순이었음"으로 마감

**두 번째 bullet — 주목할 수치 조합 (해당 시에만)**
- 상위 항목 합산, 특정 항목 집중도 등 수치적으로 의미 있는 조합만 기술
- 추측·해석 없이 수치적 사실만 기술
- 해당하는 조합이 없으면 생략

### [특성별] 섹션

- 독립변수별로 bullet 1개씩 작성
- 전체 평균 대비 두드러지게 높거나 낮은 항목이 있는 경우만 기술
- 특징이 없는 독립변수는 생략
- 문장 형식은 아래 3가지 패턴 중 상황에 맞게 선택

  패턴 A — 집단 간 비교:
  {독립변수}별로는, {하위집단A}의 경우 {항목명} 비율이 {비율}%인 반면, {하위집단B}의 경우 {비율}%로 두 집단 간 차이가 있었음

  패턴 B — 특정 집단 강조:
  {독립변수}별로는, {하위집단명}의 경우 {항목명} 비율이 {비율}%로 타 {독립변수} 대비 상대적으로 높았음/낮았음

  패턴 C — 순위 비교:
  {독립변수}별로는, {하위집단A} {비율}%, {하위집단B} {비율}%, {하위집단C} {비율}% 순으로 차이가 있었음

### 문장 형식 규칙

- 문장 처음에 **분석 기준**을 명시하고 뒤에 쉼표(,)를 찍을 것
  - 예: `RISE 사업별로는,`, `산업 분야별로는,`, `종업원 수별로는,`
- 대상 뒤에 **'~의 경우'**를 붙여 주어와 수치를 분리할 것 (쉼표 없음)
  - 예: `참여의 경우`, `미참여의 경우`, `화학의 경우`
- 단순 수치 나열 대신 **'~ 비율이 00%로'**와 같이 명확한 표현을 사용할 것
  - 예: `현장 즉시 적용 가능한 실무 중심 비율이 51.4%로`

### 공통 문체 규칙
- 서술어: "~이었음", "~높았음", "~낮았음", "~순이었음" (명사형 종결)
- 볼드·이탤릭 등 강조 서식 사용 금지
- 0% 또는 빈값(-)은 해당 항목 언급 생략
- 추측·원인 분석·맥락 해석 문장 일체 금지
- 비율은 소수점 포함 원본 수치 그대로 사용

## 출력 샘플 (A5 기준)

## A5. 세부프로그램 만족 이유 (N=140, 복수 응답)

### 전체
* 세부프로그램 만족 이유로 현장 즉시 적용 가능한 실무 중심이 41.4%로 가장 높았으며, 최신 기술·동향 반영 22.9%, 실습·프로젝트로 역량 향상 17.9% 등의 순이었음
* 현장 즉시 적용 가능한 실무 중심과 최신 기술·동향 반영을 합산하면 64.3%로, 응답의 절반 이상이 두 항목에 집중되었음

### 특성별
* RISE 참여 여부별로는, 참여 기업의 경우 현장 즉시 적용 가능한 실무 중심 비율이 51.4%인 반면, 미참여 기업의 경우 30.3%로 참여 기업 대비 낮았음
* 산업 분야별로는, 의료헬스케어의 경우 현장 즉시 적용 가능한 실무 중심 비율이 60.0%로 타 산업 분야 대비 상대적으로 높았음
* 종업원 수별로는, 1~9명의 경우 현장 즉시 적용 가능한 실무 중심 비율이 44.2%로, 10~29명(32.3%), 30명 이상(42.9%) 대비 가장 높았음
