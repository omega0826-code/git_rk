## 1. 한글 파일명 인코딩 오류

| 항목 | 내용 |
|------|------|
| 버전 | v1.0.0 |
| 상태 | ✅ 해결 |
| 관련 | [Changelog v1.0.0](../logs/changelog.md) · [Error Report #1](../logs/error_report.md#1-한글-파일명-인코딩-실패) |

**증상**: `[ERROR] 파일을 찾을 수 없습니다: report_???_???...`

**원인**: cmd.exe CP949 → UTF-8 변환 실패

**해결**: `run_now.py` 래퍼 스크립트 사용

## 5. 특성별 문장 형식 변경

| 항목 | 내용 |
|------|------|
| 버전 | v1.2.0 → v1.2.1 |
| 상태 | ℹ️ 참고 |
| 관련 | [Changelog v1.2.0~v1.2.1](../logs/changelog.md) |

**v1.2.0 변경**: 분석 기준 뒤 쉼표 + `~의 경우,` + `비율이 00%로` 추가
**v1.2.1 변경**: `~의 경우,` → `~의 경우` (쉼표 제거)

| 버전 | 출력 형식 |
|------|-----------|
| v1.1.0 | `종업원 수별로는 30명 이상은 예 5.7%로` |
| v1.2.0 | `종업원 수별로는, 30명 이상의 경우, 예 비율이 5.7%로` |
| v1.2.1 | `종업원 수별로는, 30명 이상의 경우 예 비율이 5.7%로` |

**영향**: 동일 보고서 내 일관성 유지 시 동일 버전으로 재생성 권장
