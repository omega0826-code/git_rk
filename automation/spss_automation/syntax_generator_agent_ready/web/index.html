SPSSWEB UIv1.0.1

브라우저에서 바로 실행하는 SPSS 자동화

`start.bat` 또는 `launch_web_ui.hta`로 서버를 띄우면, 이 화면에서 라벨 생성, 분석 Syntax 생성, 매크로 생성, SPS↔MD 변환까지 한 번에 처리할 수 있습니다.

실행 방식브라우저 UI + 로컬 Python 처리
결과 위치`web_output/세션ID/` 폴더
주의순수 HTML만으로는 로컬 Python을 직접 실행할 수 없습니다.

사용 순서

일반 사용자가 바로 쓸 수 있게 핵심 단계만 남겼습니다.

1
실행기 열기`start.bat` 또는 `launch_web_ui.hta`를 실행하면 브라우저가 자동으로 열립니다.
2
입력 파일 업로드필수 파일을 클릭하거나 끌어다 놓으세요. 샘플 파일도 바로 받을 수 있습니다.
3
결과 다운로드실행 후 생성된 `.sps`/`.md` 링크가 즉시 나타납니다.

샘플 파일

처음 테스트할 때 바로 사용할 수 있는 예시입니다.

⬇ CSV 샘플 ⬇ short_labels 샘플 ⬇ analysis_config 샘플 ⬇ banner_config 샘플
분석 Syntax 생성에서는 `analysis_config.json`만 올리면 내부 `label_sps` 경로가 어긋날 수 있습니다. 웹 UI에서는 `label.sps` 또는 `label_short.sps`를 함께 업로드하는 방식을 권장합니다.
